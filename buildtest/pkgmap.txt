# Failure-to-package map for the smak build-test harness.
#
# Key forms (what bt-run's failure diagnosis produces):
#   pc:<module>      pkg-config module not found
#   h:<header>       missing header, as written in the #include
#   bin:<program>    missing program (configure check, "command not found")
#   lib:<name>       linker "cannot find -l<name>"
#   cmake:<Pkg>      find_package(<Pkg>) failed (Could NOT find / no config file)
#   m4:<macro>       autoconf macro undefined when regenerating configure
#
# Values are comma-separated package names per distro family:
#   deb (Debian/Ubuntu)  rpm (Fedora/RHEL)  suse (openSUSE)  arch  apk (Alpine)
# A family missing from a line falls back to the generic lookup in bt-run
# (apt-file, dnf/zypper capabilities, pacman -F, apk pc:/cmd:). "-" means
# "nothing to install on this family".
